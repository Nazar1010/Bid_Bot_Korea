# J-Bid Korea — бот по авто с Encar

Клиент присылает ссылку на объявление Encar (или номер) — бот отвечает:

* **альбом фото** (до 10, кнопкой — ещё), без водяного знака Encar;
* **карточку**: марка, модель, комплектация, год и месяц выпуска, пробег, объём, топливо, КПП, кузов, цвет, VIN, цена в Корее, цена нового авто, гарантия;
* **короткий вердикт по истории** (тотал, утопление, угон, каркас, ДТП, прокат);
* **стоимость под ключ** во Владивостоке и до Москвы.

Кнопки под карточкой:

| Кнопка | Что показывает |
|---|---|
| 📋 Страховая история | первая регистрация, смены владельцев (с датами) и госномеров, прокат/коммерция/госорганы, все страховые случаи с датами и выплатами (запчасти, работа, покраска), тотал, утопление, угон, периоды без страховки |
| 🔧 Техосмотр | ДТП по техосмотру, затопление, каждая заменённая/отремонтированная деталь с пометкой «каркас» или «навесная», замечания по агрегатам (течи и т.п.), диагностика Encar |
| 💰 Расчёт подробно | цена авто, расходы по Корее, фрахт, пошлина, утильсбор, сбор, Владивосток, услуги J-Bid, курсы ЦБ |
| ⚡ Указать мощность | пересчёт утильсбора по реальной мощности (в Корее её не пишут) |
| ✉️ Хочу это авто | заявка админам в Telegram + кнопка «Написать менеджеру» |

Команды: `/start`, `/rates` (курсы ЦБ), `/check` (доступен ли Encar с сервера), `/stats` (для админов).

## Откуда берутся данные

Внутренний JSON API, который вызывает сам сайт Encar (без ключей):

| Что | Адрес |
|---|---|
| Карточка, фото, VIN, госномер, внутренний `vehicleId` | `api.encar.com/v1/readside/vehicle/{номер}` |
| Страховая история (CarHistory) | `…/record/vehicle/{vehicleId}/open?vehicleNo=…` |
| Техосмотр 성능점검 | `…/inspection/vehicle/{vehicleId}` |
| Диагностика Encar | `…/diagnosis/vehicle/{vehicleId}` |
| Фото | `ci.encar.com/carpicture/…` |
| Курсы | ЦБ РФ (cbr-xml-daily.ru, запасной — cbr.ru) |

Госномер и контакты дилера в ответах Encar есть, но бот их **не показывает и не хранит** (корейский закон о персональных данных PIPA).

## Установка

```
pip install -r requirements.txt
```

В `config.py` впишите:

1. `BOT_TOKEN` — токен от @BotFather;
2. `ADMIN_IDS` — свой Telegram ID (узнать: @userinfobot), туда приходят заявки;
3. тарифы с пометкой **УТОЧНИТЬ** — расходы по Корее, фрахт, Владивосток, перевод денег, санкционный маршрут.

Запуск: `python bot.py`. На bothost — главный файл `bot.py`, зависимости из `requirements.txt`.

## Первый запуск — обязательно

1. Отправьте боту `/check`. Если «поиск» и «сайт» отвечают `HTTP 200` — всё в порядке.
2. Если ОШИБКА / таймаут — Encar режет IP хостинга. Купите корейский или резидентный прокси и впишите в `ENCAR_PROXY = "http://user:pass@host:port"`.
3. Пришлите боту 2–3 ссылки и сверьте карточку с сайтом Encar (год, пробег, история, техосмотр).

## Расчёт стоимости

* **Пошлина** (физлицо, личное пользование): до 3 лет — 54/48% стоимости, но не меньше 2,5–20 €/см³; 3–5 лет — 1,5–3,6 €/см³; старше 5 — 3–5,7 €/см³. Возраст считается на дату растаможки (сегодня + `DELIVERY_DAYS`).
* **Утильсбор**: льгота 3 400 / 5 200 ₽ при ≤160 л.с. и объёме ≤3 л; иначе таблица по объёму и мощности 2026 или 2027 года (по году растаможки).
* **Сбор за оформление** — шкала с 01.01.2026.
* **Объём > 2000 см³** — Корея запрещает прямой экспорт в РФ; бот предупреждает и добавляет `SANCTION_EXTRA_USD`.
* **Электромобили** — бот не считает, предлагает ручной расчёт (другие правила: пошлина 15%, акциз, НДС).

Ставки лежат в `calc/customs.py`; при изменении законодательства правьте их там.

## Структура

```
bot.py              Telegram-бот (aiogram 3)
config.py           токен, админы, прокси, тарифы
texts.py            тексты сообщений
encar/client.py     запросы к Encar, ретраи, паузы, прокси, фото
encar/parser.py     разбор ответов → отчёт
encar/dictionaries.py  корейский → русский (марки, цвета, детали кузова, агрегаты)
calc/rates.py       курсы ЦБ
calc/customs.py     пошлина, утильсбор, сбор
calc/turnkey.py     итог под ключ
tests/              тесты на образцах ответов Encar
```

Комплектация (опции) по кодам Encar выключена (`SHOW_OPTIONS = False`): коды не документированы, включайте после сверки.
